# SEO Setup

Complete after the site is live on the production domain with a valid SSL certificate.

---

## 1. Google Search Console

### Add the Property

1. Go to [search.google.com/search-console](https://search.google.com/search-console).
2. Click **Add property**.
3. Choose **Domain** (covers both `www` and non-`www`, and `http`/`https`).
4. Enter the root domain: `jatinmishra.com` (no `https://`).

### Verify Ownership

Domain verification requires adding a DNS TXT record:

1. Google shows a TXT record value like `google-site-verification=abc123...`
2. Log in to your domain registrar (or Netlify DNS if using Netlify nameservers).
3. Add a TXT record at the root (`@`) with the value Google provides.
4. Click **Verify** in Search Console. DNS propagation may take a few minutes to an hour.

Alternative: If you can't add DNS records, use the **URL prefix** method with HTML tag verification and add the meta tag to `app/layout.tsx`. Ask the developer to add `verification` to the Next.js metadata object.

### Submit the Sitemap

1. In Search Console, go to **Sitemaps** (left sidebar).
2. Enter `https://jatinmishra.com/sitemap.xml`.
3. Click **Submit**.
4. Google will crawl the sitemap and index the pages over the next few days to weeks.

### Check for Errors

After 24–48 hours, check:
- **Coverage** — any pages with errors or warnings
- **Enhancements** — structured data (JSON-LD) validation
- **Core Web Vitals** — performance data once Google has enough visits

---

## 2. Bing Webmaster Tools (Optional but Recommended)

1. Go to [bing.com/webmasters](https://www.bing.com/webmasters).
2. Click **Add your site**.
3. Enter the production URL.
4. Verify ownership (import from Google Search Console is the easiest option).
5. Submit the sitemap: `https://jatinmishra.com/sitemap.xml`.

---

## 3. Structured Data Verification

The site has two JSON-LD blocks in the `<head>`:
- `WebSite` schema (site name, URL, description)
- `Person` schema (name, URL, job title, LinkedIn `sameAs`)

Verify they parse correctly:
1. Go to [search.google.com/test/rich-results](https://search.google.com/test/rich-results).
2. Enter the production URL.
3. Confirm both blocks are detected without errors.

---

## 4. Open Graph Verification

Test how the site appears when shared on social media:
- Facebook: [developers.facebook.com/tools/debug](https://developers.facebook.com/tools/debug)
- Twitter/X: [cards-dev.twitter.com/validator](https://cards-dev.twitter.com/validator) (requires login)
- General: [opengraph.xyz](https://www.opengraph.xyz)

Verify:
- [ ] Title: `Jatin Mishra - Freelance Website & Business Consulting`
- [ ] Description is present
- [ ] OG image (`/og-image.png`, 1200×630 px) appears correctly
- [ ] No "inaccessible" or missing image errors

---

## 5. Sitemap and Robots

The sitemap and robots files are generated at build time by Next.js:

- **Sitemap:** `https://yourdomain.com/sitemap.xml`  
  Generated by `app/sitemap.ts` — currently includes only the homepage. Expand this file when new routes are added.

- **Robots:** `https://yourdomain.com/robots.txt`  
  Generated by `app/robots.ts` — allows all crawlers on `/` and points to the sitemap.

> Both files use `NEXT_PUBLIC_SITE_URL` for all URLs. Confirm this env var is set to the correct production domain.

---

## 6. Ongoing SEO Maintenance

- Check Google Search Console for crawl errors monthly.
- Update `app/sitemap.ts` when new public pages are added.
- Re-submit the sitemap after major structural changes.
